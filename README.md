Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22) writes one original fortune-cookie line for a software developer to `/output/entry.txt`:

> The code you wrote at midnight will be reviewed by someone who slept, and that someone is you.

Run it with:

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
